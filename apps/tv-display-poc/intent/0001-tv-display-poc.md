# Intent: TV display POC

## Why

I'm choosing how to put the Story board on the living-room TV from my MacBook Air (research/tv-display). I need a simple site I can run on its own, without Bloodtower, to see and hear what the TV shows compared with the Mac display.

## What I want

A single website, run from the Mac only, with one page of tests. Each test has a button.

1. **Sounds:** play test sounds, including a beep-and-flash sync test.
2. **Moving image:** a simple looping animation.
3. **Pan image:** a slow pan over an existing game image (the landing hero).
4. **Speaking image:** the Keeper portrait talking, shown in the real dialog frame.
5. **Reference images:** images that show how art looks on the TV versus the Mac screen.
6. **Black-on-black images:** near-black ramps and dark-on-black detail, so I can see the darkest detail our game art can use on each screen.
7. **Readout:** show the viewport size, pixel ratio and fullscreen state so I can paste it into the experiment log.

## Rules

- Reuse existing Bloodtower images where possible. Everything else is simple images that represent what is being tested.
- No Bloodtower server, no tower, no iPads. It must run on its own.
- Mac only. No phone or iPad layouts.
- Built for a 16:9 fullscreen window, tested at 1920×1080 and 3840×2160.

## Done when

I can open it on the Mac, share it to the TV, run every test, and record what I saw in research/tv-display/tv-experiments.md.

## Not wanted

- Anything that touches the tower.
- Settings, accounts, saved data.
- Polish. It is disposable.
