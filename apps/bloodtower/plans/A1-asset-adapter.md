Process: `docs/sdlc.md`, Full tier. One branch, worktree and PR per step.

## Shape

```text
packs/<story>/ (pack.yaml, cast.yaml, script.yaml, assets[])
   │  pnpm assets:needs <story>        (src/assets: reads the pack with the pack-v2 reader)
   ▼
asset-job.json ──► @asset-studio/cli render [--ai] ──► work folder (masters, drafts, status index; outside git)
   ▲                                                         │  Bob approves or rejects in the studio
   │  "redo <ID>: <note>" (bt-assets skill → notes)          │
   │                                                         ▼
   │                                        asset-studio export → export-index.json, <hash> files, camera.json (0.3)
   │                                                         ▼
   │                                        pnpm assets:pack <story>   (BT lint, then copy)
   │                                                         ▼
   └──────────────────────────────── packs/<story>/assets/{avatars/<id>/ (0.3), <hash>.webp|m4a, index.json}
```

- **Status comes from asset-studio** (DEC-839). The job carries none. `assets:pack` copies each file's status from asset-studio's `export-index.json` into the pack's `index.json`.

- **`src/assets`** (package `bloodtower-assets`) is a new part, next to the pack lint in `src/server`, which it calls (DEC-396). It holds no game rule. It reads packs through `bloodtower-protocols`' pack-v2 schemas, and calls `@asset-studio/cli` as a library.
- **The pack keeps its format** (DEC-385). `assets[]` in `pack.yaml` stays the pack's declared list. `index.json` is generated by `assets:pack`, never edited by hand, and maps each ID to its shipped file (DEC-202, DEC-386).
- **Packaging ships only what the game plays:** finals, plus drafts when `--drafts` is given for a playtest (R-AST-ORG-7). Masters, WAVs and rejected drafts stay in the work folder (DEC-386).

## Out of scope

- The asset-studio code itself: P2 in its own repo.
- Engine fallback to the engine's default asset (DEC-199) beyond what the loader does today. A1 makes the index loadable; a later plan wires the engine slots.
- The funeral POC's code (frozen). The import in step 6 only reads its files.
- `asset-studio-mac` (DEC-403).
