# 0001 — Prototypes

I want a set of throwaway prototypes to prove the saga game's design before
Bloodtower builds it: Story board layouts on the TV, a day's turn loop, and each
set-piece type (Tomb, Cave, Encampment, Fortress, later Ruins and Shrine).

They run in a browser on the Mac or the TV, use the tower only when needed, and
an iPad only when a test needs touch. Each one should tell us what to change in
the design.
