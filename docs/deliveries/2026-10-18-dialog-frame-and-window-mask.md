## Notes for the swap PRs

- `/board/` is served in dev through the new symlink. `serveStatic` (`src/server/server.ts`) has an app-public fallback list (`/avatars/`, `/landing/`, `/audio/`). If `out/board/` is missing after `pnpm build`, add `/board/` there in the DialogFrame swap PR. The window-mask files sit under `/landing/` and need nothing.
- CSS `mask-image` uses alpha by default, which is why the mask PNGs carry alpha (gray = alpha).
- The hero has no village, so "windows" means the single tower window plus the stair lanterns and the lamp post. The moon and the bright cloud edges are excluded on purpose.
