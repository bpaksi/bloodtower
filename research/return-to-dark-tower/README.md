## Product line timeline

| Date | Event |
|---|---|
| 1981 | Milton Bradley *Dark Tower* |
| Aug 2018 | RtDT announced at Gen Con |
| Jan–Feb 2020 | Kickstarter: $4M+ against an $850k goal; Alliances and Dark Horde offered alongside |
| Nov 2021 | Companion app v1.0 |
| 2021–22 | Base game, Alliances and Dark Horde delivered to backers and retail |
| Aug 2022 | BackerKit: 2nd printing + Covenant, ~$2.05M from 17,068 backers |
| 2023 | Covenant delivered; app v1.3.1 adds Covenant (Sep 2023) |
| Oct 2025 | Expeditions Kickstarter: $1.49M from 11,665 backers; app v1.3.7 |
| Sep–Nov 2026 | Expeditions fulfillment underway; retailer reprints of base, Alliances, Covenant and Dark Horde listed for Oct 2026 |
