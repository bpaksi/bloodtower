# Dracula 1.0: set pieces per game length

Status: decided by Bob, 2026-10-28 ([DEC-508](../../game-design/cards/DEC-508.md)). This replaces the 5-night table (ruling 12). The full table, the crypt and the beats are kept in [dracula-v2](../dracula-v2/set-piece-counts.md).

1.0 ships Short and Standard only (DEC-502). Both lengths play the same ten set pieces, all plain scenes. Standard gets more encounters and stronger foes, not more scenes.
