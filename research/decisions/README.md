# research/decisions

Short records of cross-app decisions: what was decided, why, and what it affects. One file per decision, numbered `NNNN-<slug>.md`.

Decisions that only affect one app stay in that app's `spec.md` decision log.

Template:

```markdown
# NNNN — Title
Date: YYYY-MM-DD · Status: accepted | superseded by NNNN
## Context
## Decision
## Consequences
```
