Bob chose Claude's recommendation, "CLI plus one studio": "I like your recommendation. Additionally, there is an existing tool. https://github.com/bpaksi/talking-avatar that does some/all of this work already."

- **CLI:** renders voice, builds Portrait lines, lints and packages, headless, so Claude can drive it through skills.
- **Studio:** one web app where Bob looks and listens, approves draft to final, and sets the things that need an eye (camera moves, glow masks). tts-explorer folds into it.
- **talking-avatar** (Bob's repo, asset contract v2) already covers the Portrait path: TTS, Rhubarb mouth timing, `line.json` and m4a, the folder validator, and the `<TalkingAvatar>` player that Bloodtower pins at 0.1.0. Its CLI is not published yet. The asset tools use it for Portraits rather than redoing that work.

Rejected: one studio app only, one tool per media kind, and keeping today's tools.
