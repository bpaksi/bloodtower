- **Layout:** `packs/<story>/assets/` holds a story's shipped files, with its `index.json` (DEC-386). The engine defaults live the same way in `packs/base/assets/`. There is no separate `assets/shared` or `rendered/` folder. Masters and drafts stay in asset-studio's work folder outside git.
- **Slot IDs:** `<kind>.<entry>` plus an optional `~<variant>`, lowercase kebab-case. For example `foe.vampire`, `foe.vampire~angered`, `foe.undead~angered` (an attribute default, DEC-621), `place.village`, `painting.n2-funeral`, `portrait.count~angry`. The kind is the slot kind of DEC-535.
- **Script lines** keep `scene.moment~variant` and event moments `scene.<event>` (R-AST-ORG-10, R-AST-ORG-13). The `.private.<hero>` part is dropped, since nothing is private (DEC-057).
- **The engine** asks the index for an ID and never uses a path.
