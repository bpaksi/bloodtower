Found by the first probe when *The Last Stand* finished chapter 3's quests. The chapter loop ends a chapter as won "when every quest is done" (MEC-033 .11), and the game ends on "finale won" (MEC-032 .42). Read that way, the game is won before the Tower is entered (MEC-076, DEC-645).
