Bob chose "One per loop". Each loop card (MEC-032 to MEC-039) gets one diagram. It runs in template order: Enter, Start point, Body (the repeat), Exit, Close, End point. An inner loop shows as one node that calls that loop's own diagram. Rejected: a diagram per template row (the loop's shape would be in none of them) and one diagram for the whole stack (too big to review).
