Bob chose "All four closed". Every manifest entry carries a Type, Subtype, Class and SubClass, each from a fixed list in the engine schema. The engine may branch on any level, never on an entry's name or ID. A story uses only listed values; a new value is an engine change for every story (DEC-049). Rejected: Type and Subtype closed with Class and SubClass open to stories, and all four open as plain tags.
