Bob chose "All four closed", then: "The taxonomy levels are only there for describing the idea, the design can work out if they are needed." Every manifest entry carries type attributes, each from a fixed list in the engine schema. The engine may branch on those attributes, never on an entry's name or ID. A story uses only listed values; a new value is an engine change for every story (DEC-049). Type, Subtype, Class and SubClass describe the idea; how many levels each kind of entry needs is Q-322. Rejected: open levels a story invents, and plain tags.
