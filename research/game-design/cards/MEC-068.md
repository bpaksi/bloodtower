**What:** The tower's lights and sounds for a moment. Every engine moment has a default; a story may swap any, and each set piece picks its own.

**When:** For each set piece, and a signature cue for the villain the table learns to dread.

**Why:** The tower is the game's centrepiece; a cue the story owns makes it feel alive in this story.

**Pack:** cue overrides and set piece cues (§6).

| Count | Short | Standard | Long |
|---|---|---|---|
| Floor | 0 | 0 | 0 |
| Target | 1 per set piece + the villain's | 1 per set piece + the villain's | 1 per set piece + the villain's |
