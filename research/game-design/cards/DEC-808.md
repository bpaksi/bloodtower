Bob picked "Drop from spec" (Claude's draft) for GitHub issue #291.

The board the map tool exported in #286 has no `river_crossings` (`main` had 2 before). Both pairs are still adjacent, and no engine rule reads crossings. `apps/bloodtower/spec.md` no longer says base packs hold them. If a rule needs a crossing, it comes back with a map-tool export behind it (Q-444).

Left in the code: `river_crossings` is still an optional field in the pack schema (`protocols/pack-v2/base.ts`), defaulting to empty. Removing it is a small 1.0 cleanup, not needed for play.
