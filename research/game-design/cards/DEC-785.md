Bob picked "Playthroughs first" (Claude's draft). The steps, in order:

1. **Rule on PR #371:** DEC-757 to DEC-784, and the Dracula deck (DEC-783).
2. **Reconcile:** rule on Q-423 to Q-431 from the audit.
3. **Virtual playthroughs:** probes of Dracula on the 1.1 engine (DEC-634). They need the deck, not the finished script.
4. **Deliverables:** the 1.1 screens, UI and cues.
5. **Numbers pass,** with the simulator.
6. **Plan,** then its requirement review and Bob's gate.

**Script and assets (IDEA-153):** start after step 3, so they are written once, against rules that have held up in a played game. They can then run alongside the code.

**Changes to DEC-784:** the reconciliation and probes go before the deliverables, because a probe that changes a rule would otherwise change a screen as well.

**Holds:** code still waits for 1.0 to ship and the Tomb to be playtested (DEC-486, DEC-784).
