Every item a hero takes shows its printed card name beside any story name, so the table can find the card in the deck (DEC-757). A story item with no card says "app only".

- **Battle reward** (UI-040): it names the pile drawn from, potion, gear or treasure, which follows the foe's level (DEC-758). A fall-through to the next pile down says so.
- **Fifth treasure** (DEC-424): the hero's iPad shows all five and asks which one goes back, the new one included. The board names the card to return to the deck.
