Bob chose "Text block in the MEC card". Each loop card holds its diagram as one fenced block, one node per line: the node's number (for example MEC-034.3), its kind (DEC-268), a short label and the IDs it uses (UI-, CUE-, DEC-…). Node numbers are stable like card IDs and are never reused. The workbench draws the block as a strict railroad (DEC-269). Rejected: one card per node (hundreds of files, a slow review) and Mermaid (it draws flowcharts, not railroads).

Drawing the block in the workbench is app work on its own branch, apart from this design session.
