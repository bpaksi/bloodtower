Bob: "the iPad is to be treated as a HID. Instructions, questions, images, sounds must have a board node."

In a loop diagram, a prompt node is only the iPad taking input. Whatever the players read, see or hear (an instruction, the question being asked, an image, a sound from the board) is a board node of its own, placed before the prompt it goes with. So every prompt has a board node before it that asks its question.
