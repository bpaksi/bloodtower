Designed, not built. A single icon button on the acting group's iPad, shown at the group's turn start and during a battle. When at least one held card or virtue can be used now (DEC-410), the icon is marked, for example with a glow and a count. Otherwise it looks quiet. Pressing it opens a centered dialog, like the Menu (UI-033). There is one row per usable card or virtue, with its name, icon and effect, and a Use button. A card that needs a choice (a hero, a building) asks for it inside the dialog. Closing the dialog changes nothing. The game never waits on this button (DEC-479). Icons and text only, no art (DEC-201).
