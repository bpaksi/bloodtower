Designed, not built. A slim bar across the bottom of every iPad screen, idle card (UI-029) included. Back, Replay and Menu are centered. Menu is a gear icon. Back and Replay keep an icon and a text label. A control that cannot be used is greyed, never hidden, so the bar never shifts. The screen's corner frames are theme B, engraved manuscript corners (DEC-233). Illusionist holds that mock and asset for when this chrome ships.
