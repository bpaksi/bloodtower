**What:** What winning a set piece pays: a story item, money, an Advantage or a companion.

**When:** Every set piece. Make the reward fit the scene and help the next chapter.

**Why:** A reward is the table's proof the scene mattered, and it makes the heroes stronger for the finale.

**Pack:** the set piece's outcome effects (§3.3, §0.2).

| Count | Short | Standard | Long |
|---|---|---|---|
| Floor | 1 per set piece | 1 per set piece | 1 per set piece |
| Target | 1 per set piece | 1 per set piece | 1 per set piece |
