Bob: "the game engine need to allow for highly built out feature but can back down based on data. i.e. A frightened foe may have an image, but an Angered foe might not and therefore should show default instead." The engine is built for the full 1.1 feature set. Each optional piece of an entry (a state's image, a line, a cue) falls back to the default when the data leaves it out, so a thin 1.0 manifest and a rich later one run on the same engine. A missing variant is not an error; a missing default is, and the linter (DEC-062) catches it.
