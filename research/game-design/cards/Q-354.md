Found by the first probe at the close of day 1 (MEC-034 .23). The adversary hunts the building with the most skulls and adds skulls when it arrives (DEC-052), and it strikes heroes it reaches before the finale (DEC-053). But game setup (MEC-032 .21 to .34) has no node that places it. No card says where it starts, how many spaces it moves a day, or how many skulls it adds.

**Answered for 1.0 by DEC-644 (Bob, 2026-10-30):** the adversary waits in the locked Tower from the start, with no board token; setup never places it and MEC-034 .23 is skipped. Its start space, daily move and skulls added matter only when roaming (DEC-052, DEC-053) returns in 1.1. Status fixed in the 2026-10-31 v1 readiness review.
