Bob chose "Stable IDs through an index". Engine assets live in one engine folder; each story's live in its own story folder. Manifests and slots name an asset only by its stable ID, never by path. Each folder has an index that maps an ID to its file, media kind (DEC-200), size and captions. To find an asset, the engine looks the ID up in the story's index first, then falls back to the engine's default (DEC-199). Rejected: paths in the manifest, and one library shared by every story.
