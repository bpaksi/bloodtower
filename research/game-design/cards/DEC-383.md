Bob picked "asset-studio" and asked: "Is there anything BT specific about this app. If not I'd like to keep it in its own repo. Possible even folding in the existing talking-avatar if it makes sense to consolidate." Claude split it, and Bob chose the recommendation: "talking-avatar is on NPM. we'll need to change that."

- **asset-studio** (own repo): bpaksi/talking-avatar is renamed and grows. It holds the generic parts: voice from text, talking-avatar lines (TTS, Rhubarb, player), picture prep per screen size, the Painting editor for camera moves and glow masks, draft-to-final review, the content-hashed cache and a generic ID-to-file index. A CLI and a studio web app (DEC-382). Neutral fixtures only; no RtDT art in the public repo.
- **Bloodtower adapter:** turns a pack into a generic job (cast, lines, pictures, with DEC-349 deciding which lines are voiced), runs BT's lint (DEC-207, DEC-348, readiness), packages the result into the pack (DEC-202), and keeps tower cues, which are capabilities, not media.
- Bloodtower takes asset-studio from npm at exact pins, as it does talking-avatar today.

Rejected: a new repo next to talking-avatar, and an app inside the BT monorepo.
