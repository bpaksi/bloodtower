DEC-596 step 3 walks these in order, narrowest first:

| Kind | Order |
|---|---|
| Foe | first trait, second trait, size, rank |
| Item | traits (in listed order), timing, kind |
| Virtue | class, kind, source |
| Corruption | effect kind |
| Place | building, region, terrain, kingdom |
| Event | terrain, kingdom, tone |

- **Two traits:** the entry lists its traits in order, and the first is its primary. A vampire listed as Undead, Magic tries undead art before magic art. The manifest lint requires the order to be written, so it is never left to chance.
- **Empty values** (a place with no building, an item with no traits) are skipped.
