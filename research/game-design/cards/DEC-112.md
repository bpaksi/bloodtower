"The story needs options. 1 player per kingdom (RTDT style), All Same, All different, ... optionally the story can name the location (E, village)."

A story's manifest picks a start option:
- **One per kingdom:** as in RtDT, each hero starts alone in a different kingdom.
- **All same:** the whole party starts as one group on one space.
- **All different:** every hero starts alone, on different spaces.
- More options can be added later.

The story can also name the place, as a kingdom plus a building, for example "East, village". If it doesn't, the engine picks a sensible place (for example each kingdom's citadel). Heroes who start on the same space form one group (DEC-031). Placing the party is a core setup step (DEC-110).
