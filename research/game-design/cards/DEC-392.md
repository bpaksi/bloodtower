Bob chose both recommendations.

- **Art:** a Gemini image model, with the same key as TTS. Portraits and paintings are made from the story's style and the reference sheets (R-AST-ORG-5). The 8 mouth frames come from edits of the portrait's mouth only; the CLI then pastes just the anchor box back onto the portrait, so every frame matches outside the anchor (DEC-207). The provider sits behind an interface, so another can be added later.
- **Notes back:** with a dev flag on, the board shows the current asset ID in a corner. Bob tells Claude "redo <ID>: too bright", and a skill writes the note into the needs list for the next render. No new game UI.

Rejected: several image providers from day one, AI making portraits without mouths, an in-game flag button, and studio-only notes.
