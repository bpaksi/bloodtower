**Recommendation.** With all seals on, nobody can see a glyph at setup, so a setup check is pointless (DEC-304). The only time the map matters is a seal break.

- **At a break:** the board shows the glyph the library expects, and an iPad confirms it or picks what actually shows. The app keeps that answer.
- **The test, for Bob's tower:** before seals go on, calibrate, light each doorway, and note the glyph behind it. If the map holds, the confirm stays as a quiet check.

**Why:** this works even if the library is wrong, and the tower can't sense glyphs anyway (MEC-018).

**Not tested yet.** It needs the tower.
