Bob: "I'm worried that if the base game uses these it will slow the game down too much. There maybe times when the base game can use them but as a default game uses only stills."

A Portrait or a Painting plays voiced lines and takes time, so the base game does not put them in its own loops by default. The engine's own board moments (arrivals, building menus, battle beats) show stills with no voiced lines. A story uses Portraits and Paintings in its hooks (DEC-285). The engine may use them in a few named places, still to be listed (Q-237). Rejected: Claude's draft, where the engine used them for NPC talk, arrivals, battle beats, the opening and the outcome.
