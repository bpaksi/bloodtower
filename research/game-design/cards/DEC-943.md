D4 brief (bloodtower #504). The move map shows a fallen building's note, "This building has fallen. No one can enter." (C3/13 copy row 28), and no Enter. DEC-910 makes a fallen building with an unfinished quest marker a place to Enter, so that note would be false there.

- **Ruling:** while the space holds an open quest marker (the current chapter's, not yet done), the move map shows Enter as for any place and does not show the fallen note. The menu is "Quest", then "Leave": the labels the building menu already uses. No other entry, no Cleanse (DEC-377).
- **When the quest is done**, or the marker is not live (another chapter's, C3/19), the space is a plain fallen building again: the note shows and there is no Enter.
- **No new copy and no new screen state.** It reuses the existing Enter button and the existing building menu with two rows; the note's words are unchanged where it shows. Loremaster has nothing to write.

Reason: the simplest thing that tells the table the truth; it is how a wild quest marker already looks (DEC-641).

Not picked: show the fallen note and Enter together (the note says no one can enter); new copy for this case (one more line for a rare state, and a Copy-table round for Loremaster).

Decided by Gamewright, 2026-11-18, under Bob's delegation. Revise in playtest.
