**What:** One win scene, and one loss scene for each way the game can be lost: the engine's ways (DEC-043) plus any the story adds.

**When:** Every story. Each loss scene names the reason, so the table knows why it lost.

**Why:** The ending is the last thing the table sees; a generic loss throws away the story.

**Pack:** `endings` (§12).

| Count | Short | Standard | Long |
|---|---|---|---|
| Floor | 1 win + 1 per way to lose | same | same |
| Target | same | same | same |
