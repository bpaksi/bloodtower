Bob: "path is required entry on start up. remembered for subsequent runs. Can be changed."

asset-studio does nothing until a work folder is set. The studio asks for it on first start; the CLI stops with an error naming the setting when none is set. The path is kept in asset-studio's user settings (outside any repo, so every worktree sees the same one) and can be changed in the studio or with a CLI flag. Backup is Bob's choice of folder, for example one inside the OneDrive backup. Rejected: a fixed OneDrive path, a local folder with a backup command, and a git-ignored folder in the repo.
