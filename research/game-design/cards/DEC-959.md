Gamewright, 2026-11-27, under Bob's delegation (via Warden). The bands are Bob's (DEC-823, DEC-815, DEC-816, DEC-817). This card applies them to the 1.0 pass. It does not import 1.1 placeholders.

- **Cells.** Three: 2, 3 and 4 heroes, 100 games each. The game is the v1.0 default: length unset, which is Standard (DEC-603), at normal difficulty. No solo.
- **Win rate.** DEC-823's frame. Every cell must reach about 80%, and may run up to about 95%. The pass lifts only a cell below about 80%. A cell from 80% through 95% keeps its numbers. A cell above about 95% is flagged in the report. It is not tuned down in 1.0.
- **Hangs.** Every game ends.
- **Length and falls.** Reported per cell. No band in 1.0. They are for the G-C3 and G-C4 table read, not a pass or a fail.
- **Moving a number.** A number moves only when the sim and the G-C3 and G-C4 gates agree (Q-C5-05). Any change to a 1.0 tuning value is listed in the #464 PR for Bob before merge (DEC-817).
