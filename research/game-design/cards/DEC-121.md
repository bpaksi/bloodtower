Bob: "spells are benefits from Virtues. Each character class has a set of Virtues." A hero starts with some virtues active and unlocks the rest. A spell virtue is limited by uses (DEC-122); the others are passive or limited by uses too. A magic user's set is mostly spells, a fighter's has few or none.
