title: "When several heroes cast spells in one round, in what order do they cut the foe?"
status: answered
layer: core
links:
  - { rel: part-of, to: AREA-016 }
  - { rel: affects, to: MEC-038 }
---
Found by the first probe in *The Last Stand* (a level 3 foe with a count of 15). With Lightning (−6) and Fireball (halves) in the same round, the order changes the result: 15 − 6 = 9, halved to 4, or 15 halved to 7, minus 6 = 1. MEC-038 .8 says only "spells cut the foe".
