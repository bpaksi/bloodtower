Bob adopted IDEA-031 and chose "Merge into one band". Every loop provides its own board content. A loop that is running an inner loop adds only a segment to one shared band, outermost on the left. The innermost loop paints the whole middle. White space is fine, but an empty screen is not: a loop waiting on an iPad shows that it is waiting. The edge frame of DEC-186 is this band. Rejected: true nesting with optional borders, and showing only the parent's border.
