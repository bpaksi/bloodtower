Bob chose "Web studio now, Mac shell later". The studio's preview must be the real board player (the React `@asset-studio/player`), so the studio is a local web app first. Later, `asset-studio-mac` is a thin SwiftUI app, which bama's skills can build, that hosts the same studio in a web view and adds the native parts: a folder picker for the work folder (DEC-394), drag and drop from Finder, the Gemini key in Keychain, and a Dock icon. Installing the bama plugin is Bob's call when that step comes. Rejected: a native studio with a Swift player, and web only.
