"I think we should add 1 card for every RTDT game piece (even if we don't plan on using it) and 1 card for every Tower sound, glyph, light, drum movement ... This would allow us to quickly ask what game pieces are we using." Tower cards: each sound (113), glyph (5), seal (12), light (24), light effect (6), light sequence (21) and drum (3). A piece is in use when a card links `uses` to it; `parked` when we decide against it.
