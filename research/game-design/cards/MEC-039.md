- **Owner:** engine. No entry points (DEC-140).
- **Enter:** .1 to .19. Starts after app startup (DEC-273).
- **Body:** .20 to .23, one game per pass.
- **Exit:** .23, Done for tonight.
- **Close:** .24 to .26.
- **Result up:** none (top level).
- **Screen, UI, art, sound:** on each node's home card (DEC-277). Debug only: the status strip (UI-008).

The first ID on each line is the node's home card (DEC-277). The board goes down before the tower block, since orienting needs the kingdom edges on the table (DEC-104). Nodes .11 and .12 are a placeholder until the tower-poc prototype settles the glyph prompts (DEC-103).

```railroad
enter
  .1  board   Join QR, open until every hero is claimed      UI-010 DEC-274
  .2  prompt  Wait for the first iPad to join                SCR-015 DEC-274
  .3  board   Base board setup steps                         SCR-022 DEC-152
  .4  prompt  Board is set up (any iPad)                     SCR-022
  repeat
    .5  prompt  Connect Tower, or Play without Tower         SCR-005 DEC-275
    .6  check   Connect or without?                          DEC-275
      track connect
        .7  change  Connect and calibrate the tower          DEC-104 SCR-005
        .8  tower   Calibration spin                         CUE-011
      track without
    .9  check   Tower ready, or playing without? No: again   DEC-275
  .10 check   Tower in play?                                 DEC-275
    track yes
      .11 prompt  Which glyphs are visible?                  DEC-103
      .12 change  Set the drums from the answer              DEC-103
      .13 tower   Light one side                             MEC-017
      .14 prompt  Which kingdom does it face?                MEC-017
      .15 change  Set the tower's facing                     MEC-017
      repeat
        .16 prompt  Volume 0, 1 or 2                         SCR-006
        .17 tower   Dungeon Complete at that volume          SND-058 SCR-006
        .18 prompt  Keep this volume?                        SCR-006
        .19 check   Kept? No: again                          SCR-006
    track no
body
  repeat
    .20 call    Game loop, new or Play again                 MEC-032 DEC-213
    .21 board   Session screen                               SCR-021
    .22 prompt  New game, a past game's Play again, or Done for tonight   SCR-021 DEC-214
    .23 check   Done for tonight? No: next game              DEC-214
close
  .24 board   Goodbye and teardown checklist                 SCR-020
  .25 check   Tower in play?                                 DEC-275
    track yes
      .26 tower   Tower to idle                              CUE-012 SCR-020
    track no
end
```
