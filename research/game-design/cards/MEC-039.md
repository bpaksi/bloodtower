- **Owner:** engine. No entry points (DEC-140).
- **Enter:** .1 to .14. Starts after app startup (DEC-273).
- **Body:** .15 to .18, one game per pass.
- **Exit:** .18, Done for tonight.
- **Close:** .19 to .21.
- **Result up:** none (top level).
- **Screen, UI, art, sound:** SCR-005, SCR-006, SCR-020, SCR-021; the status strip (UI-008, debug only); the volume test's clip (SND-058).

```railroad
enter
  .1  board   Join QR, open until every hero is claimed      DEC-153 DEC-274
  .2  prompt  Wait for the first iPad to join                DEC-274
  repeat
    .3  prompt  Connect Tower, or Play without Tower         SCR-005 DEC-275
    .4  check   Connect or without?
      track connect
        .5  change  Connect and calibrate the tower          SCR-005
        .6  tower   Calibration spin
      track without
    .7  check   Tower ready, or playing without? No: again
  .8  check   Tower in play?
    track yes
      repeat
        .9   prompt  Volume 0, 1 or 2                         SCR-006
        .10  tower   Dungeon Complete at that volume          SND-058
        .11  prompt  Keep this volume?                        SCR-006
        .12  check   Kept? No: again
    track no
  .13 board   Base board setup steps                         DEC-152
  .14 prompt  Board is set up (any iPad)                     DEC-152
body
  repeat
    .15 call    Game loop, new or Play again                 MEC-032 DEC-213
    .16 board   Session screen                               SCR-021
    .17 prompt  New game, a past game's Play again, or Done for tonight   DEC-214
    .18 check   Done for tonight? No: next game
close
  .19 board   Goodbye and teardown checklist                 SCR-020
  .20 check   Tower in play?
    track yes
      .21 tower   Tower to idle                              SCR-020
    track no
end
```
