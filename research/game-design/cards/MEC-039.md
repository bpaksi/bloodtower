- **Owner:** engine. No entry points (DEC-140).
- **Enter:** .1 to .25. Starts after app startup (DEC-273).
- **Body:** .26 to .29, one game per pass.
- **Exit:** .29, Done for tonight.
- **Close:** .30 to .32.
- **Result up:** none (top level).
- **Screen, UI, art, sound:** on each node's home card (DEC-277). Debug only: the status strip (UI-008).

The first ID on each line is the node's home card (DEC-277). The iPad only takes input, so every prompt follows a board node that asks its question (DEC-278). The board goes down before the tower block, since orienting needs the kingdom edges on the table (DEC-104). Nodes .13 to .15 are a placeholder until the tower-poc prototype settles the glyph prompts (DEC-103). No tower node here is optional: no story is loaded until the game loop.

```railroad
enter
  .1  board   Join QR and how to join, open until every hero is claimed   UI-010 DEC-274
  .2  prompt  The first iPad joins                           SCR-015 DEC-274
  .3  board   Base board setup steps                         SCR-022 DEC-152
  .4  prompt  Board is set up (any iPad)                     SCR-022
  repeat
    .5  board   Connect the tower, or play without it?       SCR-005 DEC-275
    .6  prompt  Connect Tower, or Play without Tower         SCR-005 DEC-275
    .7  check   Connect or without?                          DEC-275
      track connect
        .8  change  Connect to the tower                     DEC-104 SCR-005
        .9  board   Calibrating                              SCR-005
        .10 tower   Calibrate                                CUE-011
      track without
    .11 check   Tower ready, or playing without? No: again   DEC-275
  .12 check   Tower in play?                                 DEC-275
    track yes
      .13 board   Which glyphs can you see?                  DEC-103
      .14 prompt  The visible glyphs                         DEC-103
      .15 change  Set the drums from the answer              DEC-103
      .16 board   Which kingdom does the lit side face?      MEC-017
      .17 tower   Light one side                             MEC-017
      .18 prompt  The kingdom it faces                       MEC-017
      .19 change  Set the tower's facing                     MEC-017
      repeat
        .20 board   Pick the tower's volume                  SCR-006
        .21 prompt  Volume 0, 1 or 2                         SCR-006
        .22 tower   Dungeon Complete at that volume          SND-058 SCR-006
        .23 board   Keep this volume?                        SCR-006
        .24 prompt  Keep, or try another                     SCR-006
        .25 check   Kept? No: again                          SCR-006
    track no
body
  repeat
    .26 call    Game loop, new or Play again                 MEC-032 DEC-213
    .27 board   Session screen: New game, past games, Done for tonight   SCR-021 DEC-214
    .28 prompt  New game, a past game's Play again, or Done for tonight   SCR-021 DEC-214
    .29 check   Done for tonight? No: next game              DEC-214

  .30 board   Goodbye and teardown checklist                 SCR-020
  .31 check   Tower in play?                                 DEC-275
    track yes
      .32 tower   Tower to idle                              CUE-012 SCR-020
    track no
end
```
