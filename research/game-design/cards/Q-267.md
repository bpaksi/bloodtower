Bob: "Does the RTDT virtues map good to BT virtue system. If they do then we should use the RTDT virtues maybe with minor tweaks. this has many benefits." The analysis is in [items-and-virtues.md](../../return-to-dark-tower/items-and-virtues.md): of 20 known base virtues, 7 are Advantages as they stand, Swift fits as a perk, Blessed is close to a guard, the rest run on warriors, spirit, Cleanse, Reinforce or home kingdoms, and none is a spell. The box has 16 tiles for 36 class virtues. Bob chose to borrow names and ideas, app only (DEC-368).
