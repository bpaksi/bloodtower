"Let's start with 6, but make it easy to add later."

Each hero is one entry in the engine's hero data: name, role, attribute values, innate abilities, portrait and voice. Adding a hero means adding an entry and its assets; no screen or rule changes. The pick screen lays out the whole pool, not a fixed 6. The table seats N of them, chosen in Game settings, not the whole pool (DEC-098).

**Ruled 2026-11-26 (Bob):** In 1.0, heroes have no voice. The base pack's `vo.hero-*` lines are retired; only the Loremaster is voiced (DEC-349, DEC-902). The hero schema still requires a `voice` id, so each hero entry in `packs/base/pack.yaml` keeps its `voice:` id until that field is made optional.
