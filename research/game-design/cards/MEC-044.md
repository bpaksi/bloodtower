**What:** A narration at the start and end of each chapter and set piece. The end one hears the outcome.

**When:** Start of every chapter and set piece at least. Add an end for each outcome (set piece: won, left, failed) so each result lands its own way.

**Why:** Entry points are where the story talks to the table without asking anything (DEC-139); they carry the plot between scenes.

**Pack:** start and end moments per chapter and set piece (§4).

| Count | Short | Standard | Long |
|---|---|---|---|
| Floor | start of each | start of each | start of each |
| Target | start + one end per outcome | start + one end per outcome | start + one end per outcome |
