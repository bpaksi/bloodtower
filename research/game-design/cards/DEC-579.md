Type, Subtype, Class and SubClass become named attributes per kind, each a closed engine list (DEC-499):

| Kind | Attributes | Review |
|---|---|---|
| Foe | rank (foe, lieutenant, disaster, adversary); traits (2 of Beast, Magic, Humanoid, Melee, Undead, Stealth, DEC-068); size (group, lone, DEC-533) | Bob, 2026-10-29: "Rank, traits, size" |
| Item | kind (gear, potion, treasure, story item); traits; timing (turn, battle, DEC-483) | proposed |
| Virtue | kind (spell, guard, Advantage, perk, DEC-367); source (intrinsic, tile, kingdom); class | proposed |
| Corruption | effect kind (DEC-069) | proposed |
| Place | terrain; building (citadel, sanctuary, village, bazaar, tavern, none) | proposed |
| Companion | role (DEC-333) | proposed |
| Event | terrain; tone (good, bad, neutral) | proposed |

The engine branches only on these. DEC-501's fallback order then runs through each kind's attributes, broadest last.

Ruled by Claude at Bob's request (2026-10-29: "where possible make a good choice").
