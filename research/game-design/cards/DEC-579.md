Type, Subtype, Class and SubClass become named attributes per kind, each a closed engine list (DEC-499):

| Kind | Attributes | Review |
|---|---|---|
| Foe | rank (foe, lieutenant, disaster, adversary); traits (2 of Beast, Magic, Humanoid, Melee, Undead, Stealth, DEC-068); size (group, lone, DEC-533) | Bob, 2026-10-29: "Rank, traits, size" |
| Item | kind (gear, potion, treasure, story item); traits (the RtDT traits it matches for Advantages, DEC-068); timing (turn, battle, DEC-483) | Bob, 2026-10-29: "Kind, traits, timing" |
| Virtue | kind (spell, guard, Advantage, perk, DEC-367); source (intrinsic, tile, kingdom); class (the hero class that owns it, empty for a shared tile) | Bob, 2026-10-29: "Kind, source, class" |
| Corruption | effect kind (DEC-069); size and timing come with the effect, as on any card | Bob, 2026-10-29: "Effect kind only" |
| Place | terrain; building (citadel, sanctuary, village, bazaar, tavern, none); kingdom (Arisilon, Brynthia, Durnin, Zenon), since kingdom unlocks and glyphs act per kingdom (MEC-009, MEC-016); region (The Great Woods, Regal Run, Long Water, none, DEC-595) | Bob, 2026-10-29: "Terrain, building, kingdom", then region added |
| Companion | role (DEC-333), proposed | Bob, 2026-10-29: "Park it for 1.1". Companions ship in 1.1 (DEC-502), so this row waits for the companions deep dive with Q-036; the 1.0 schema leaves the kind out |
| Event | terrain; tone (good, bad, neutral); kingdom, so a story can weight events per kingdom | Bob, 2026-10-29: "Terrain, tone, kingdom" |

The engine branches only on these. DEC-501's fallback order then runs through each kind's attributes, broadest last.

Drafted by Claude at Bob's request (2026-10-29: "where possible make a good choice"). Bob chose the shape in DEC-594 and reviewed each row the same day. He added kingdom to places and events and parked the companion row for 1.1. Each value list not spelled out here (terrains, item traits, the tone draw) is fixed in the engine schema, as DEC-499 asks.
