- **What can change it:** any hook that runs while a tomb is open: a chapter start, a quest step, or a room's start or end hook (DEC-540). The hook names a style, and the next room uses it.
- **1.0 is swap only.** A change replaces all six section paintings (DEC-585). Overlays (flood, fire) need extra art per style, so they wait for 1.1.
- **The map half stays the same.** 1.0 has one engine set of map tiles and doorway marks. Styled map tiles come with the other dungeon types in 1.1 (IDEA-065, DEC-593).
