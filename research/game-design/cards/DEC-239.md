Bob's answer: the tool records, for each neighbour, its compass slot, its river (whether one lies between), its terrain, and an optional note for special information. Bob's example for the note is a region label, "The Great Woods". That label is not a space (DEC-225), so the note carries text only; Q-146 decides whether it can point at the spaces it spans.
