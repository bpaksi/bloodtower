title: "Is the battle's end hook the same slot as the 'battle ends' trigger, as DEC-297 ruled for quests?"
status: answered
layer: core
links:
  - { rel: part-of, to: AREA-093 }
---
DEC-540 gives the battle loop an end hook. DEC-290 already has a "battle ends" trigger, and DEC-297 merged the quest's end hook with "quest ends". The same merge probably applies to battles, and perhaps to any trigger that matches a loop's start or end.
