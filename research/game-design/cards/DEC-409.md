Bob, after the hero tiles: "skulls will need to be tracked to a specific building. The Tower signals the engine on Drop but we must prompt the user for results. This can include 'captured' by tower, or location where skull was placed. This UI should handle the multiple skulls at one time if seals are being used and a seal is removed." He then chose "Ask right after the break".

- **Already in place:** the day's drop (MEC-034 .11 to .22) asks a kingdom for each skull or none (it stayed in the tower), then a building for each skull in turn, so a drop that frees several skulls is handled (DEC-064, DEC-092).
- **New:** right after a seal breaks (MEC-033 .21), the board asks "Did any skulls fall?" If some did, the same steps run: a kingdom for each skull, then a building for each one, and each skull takes effect (DEC-093). If none fell, one tap moves on.

Rejected: leaving freed skulls until the next day's drop, and one shared step after any tower change.
