Bob picked "About 80%". Normal should feel comfortable: a loss comes from bad luck or bad play, and hard carries the challenge. Every 1.1 number in the pass is tuned toward this one target, measured over a seeded batch of the script's plain play (DEC-814).

P-005 is at 63% now, so the pass has to lift wins by about 17 points. A real table plays better than the script, so it should land above 80%.

Not picked: 60–70%, which is where P-005 is now; about 50%; and a different target for each length.
