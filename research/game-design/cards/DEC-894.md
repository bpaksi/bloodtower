Question from C3 feature 08 (EV-07): the eval asks a Selfish holder to give a virtue tile and an item, but no give action exists, and DEC-544 says heroes do not swap tiles. Both rulings are Bob's, so both stand.

- **No new action.** 1.0 adds no hero-to-hero give. DEC-544 holds: tiles are never traded, and the give-back to the pool is the only way to shed one. Items are not traded either. The only card pass on the cards is DEC-460's Black Mark, passed on for gold, and any pass a story's own rule writes (DEC-476: "wherever a rule lets heroes pass cards").
- **The guard.** The engine has one check, "may this hero give?", in `src/engine/rules/corruption/`. It is false for a Selfish holder and true for everyone else, and receiving is never checked. Every rule that passes a card between heroes must call it first. A refused pass moves nothing.
- **Using is not passing.** Drinking or giving a potion to a present hero (DEC-129) spends the potion; no card changes hands, so Selfish does not block it. Potions are 1.1 anyway (DEC-502).
- **EV-07 test.** It runs against a stand-in pass rule that would move a tile and an item, and shows the holder's pass is refused with nothing moved, the other hero's pass to the holder works, and the holder still receives. The stand-in is test code and ships nothing a player can press.
- **Cursed** (DEC-466) stays out of C3's draw (Bob, 2026-10-31); it has no part in this guard.

Decided by Gamewright, 2026-11-12, under Bob's delegation. Revise in playtest.
