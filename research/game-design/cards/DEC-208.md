Bob: "Because of board setup I don't see the players stopping, cleaning up and then playing later. However, crash recovery probably does 90% of save and continue."

There is no Save button and only one stored game. A crash, a lost tower, Quit and Abandon all leave the autosave in place. Pick Game shows Continue while it exists, and starting a new game replaces it. Continue runs the tower check (MEC-018).
