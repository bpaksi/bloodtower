**What:** The story's names for the engine's events in the wild: hazards, disasters and windfalls. The types and their rules stay the engine's.

**When:** For each event type, so a storm or a plague reads as part of this story's world.

**Why:** Events happen every trip across the board; renamed, they keep the world consistent.

**Pack:** event names (§10). The count is event types renamed.

| Count | Short | Standard | Long |
|---|---|---|---|
| Floor | 0 | 0 | 0 |
| Target | 1 per event type | 1 per event type | 1 per event type |
