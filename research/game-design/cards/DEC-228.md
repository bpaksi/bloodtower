Bob chose "Back: acting; Replay: any". Back undoes a choice, so it belongs to the group that made it; on a waiting group's iPads it shows greyed. Replay changes nothing (DEC-210), so any iPad can ask the board for it. Rejected: both for the acting group only, both for any iPad, and Back only for the iPad that chose.
