On each present hero's iPad each round: the group's Fight or Retreat (DEC-118), then the hero's one action (DEC-129), with spells showing their uses left (DEC-122). Picking nothing is a normal attack.

**No Retreat (Bob, 2026-11-27, via Warden):** when Retreat is not offered, this screen skips Fight or Retreat and opens the action picks.

**Guard prompt (Bob, 2026-11-27, via Warden):** after the group picks Retreat, and a standing hero has a guard virtue, the iPad shows one state asking whether that hero covers the last attack (DEC-680). It is skipped when no such hero is present.

Accepted by Bob in the 2026-10-30 rulings review.
