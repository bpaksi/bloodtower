Bob: "I don't want our design to use different names than the original games." Where a Bloodtower concept matches an RtDT or DT81 element, it takes that game's name. Only a concept neither game has gets a name of its own. The renames to settle are listed in the crosswalk's Terms section.

When Bloodtower changed how the thing works, Bob decides each rename case by case (2026-10-23).

Recorded by Bob on 2026-10-23 in the design session on branch `chore/design-session-2026-10-22d`, which never merged; ported 2026-10-28 with a new ID. The renames were not applied to the other cards, which still use the old words: Q-328 asks whether to apply them.
