DEC-382 and DEC-400 have Bob set a Painting's move and focus box in the studio. DEC-385 has Bloodtower write the job from the pack on each `assets:needs`, and asset-studio never reads or writes the pack. P2 S9 had the studio write the job's `camera` field, which the next `assets:needs` would overwrite.
