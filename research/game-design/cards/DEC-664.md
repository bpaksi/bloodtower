Bob picked "Tower end hook + flag".

- **Where:** the Tower encounter loop (MEC-076) has an end hook, as every loop does (DEC-540). Proving Grounds fills it with a plain scene (MEC-077) that offers DEC-663's two options.
- **How it branches:** each option's effect is a flag (DEC-642). The win scene (DEC-144) plays the closing line whose condition matches that flag (DEC-290).
- **No new engine rule:** it uses only pieces that exist today, so any story may reuse it for branching endings.

Not picked: a win scene that holds a choice itself (a new hook shape); deferring the second ending to 1.1.
