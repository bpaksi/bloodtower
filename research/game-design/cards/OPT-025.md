Bob: "a view in 3 parts each with a panel for the corridor. if there is no corridor in the direction, a solid wall is shown."

**For:** few paintings (a corridor and a wall per direction, per tomb style), any room is a combination; each panel can change on its own (listened to, dark, cleared, the guardian's door).

**Against:** the seams between panels show; it reads as three pictures, not one room.
