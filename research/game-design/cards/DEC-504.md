Bob chose "One file per kind". The base and each story hold files such as `foes.json`, `virtues.json` and `places.json`, each with its own schema. A story ships only the kinds it changes, and each of its files patches the base file of the same name (DEC-503). Prose stays in YAML content files (DEC-061). Rejected: one big manifest, and one file per entry.
