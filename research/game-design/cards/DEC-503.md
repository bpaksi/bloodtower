Bob chose "Field patch, explicit remove". Entries match by stable ID. A new ID adds an entry. A known ID changes only the fields the story writes; a list the story writes replaces the base list whole. `remove: true` deletes the entry, and the linter (DEC-062) fails anything that still points at it. Leaving an ID out keeps the base entry, so a fix to the base reaches every story that did not change that field. Rejected: replacing the whole entry, and a story's file replacing the whole kind.
