**What:** How the heroes start: one per kingdom, all on one space, or all apart, and optionally on a named place.

**When:** Every story. Start together for a tight party story; one per kingdom for a world under threat everywhere.

**Why:** The start sets the first turns' feel: a party walking together, or scattered heroes racing to meet.

**Pack:** the start option (§1).
