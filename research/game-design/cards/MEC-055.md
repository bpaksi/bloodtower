**What:** Where each set piece starts: a highlighted first option in a building's menu, or a dungeon token in the wild. Main story points are fixed and never expire.

**When:** One for every set piece. Spread them over kingdoms so the party travels.

**Why:** A story point is how the plot shows on the board; spreading them makes the map part of the story.

**Pack:** `objective.<chapter>` sites (§9).

| Count | Short | Standard | Long |
|---|---|---|---|
| Floor | 1 per set piece | 1 per set piece | 1 per set piece |
| Target | 1 per set piece, over 2 kingdoms | 1 per set piece, over 3 kingdoms | 1 per set piece, over 4 kingdoms |
