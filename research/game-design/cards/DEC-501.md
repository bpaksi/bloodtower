Claude's proposal. The engine looks for "angered" on the entry, then the entry's default, then the default of each type attribute from narrowest to broadest (in the idea's words: SubClass, Class, Subtype, Type), then the engine default. One "angered undead" image then covers every undead foe that has none of its own, so art can be added a level at a time.

Bob accepted it on 2026-10-29. The four generic levels are now each kind's named attributes (DEC-594, DEC-579); their order is Q-338. How this meets the chapter, story and base layers is DEC-596.
