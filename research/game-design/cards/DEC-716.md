Bob picked "A press turns them" in the 2026-10-31 open-questions session.

- **Why it is needed:** the session's Enter calibrates the tower, which turns every drum to home, so a saved game's drum positions are lost on the tower.
- **The step:** Continue's piece check shows "Turn the drums to the saved game". One press sends one rotate per drum that is not already where the save has it. Nothing turns without that press (tower safety).
- **Confirm:** then a picture shows the glyphs the save expects on each side, and the table confirms it, as MEC-018's other pictures.
- **Check first:** C2 feature 10's tower run must show a rotate lands where the library says. If it does not, the fallback is a picture of each drum's saved glyph that the table turns to by hand.

Not picked: the table turns every drum by hand; a save that ignores the drums.
